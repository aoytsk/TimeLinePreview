# TimeLinePreview プラグイン

タイムライン上でサムネイルとパラメータをポップアップ表示します。

## 主な機能

- サムネイルプレビュー: ホバー中のフレームをリアルタイムにレンダリングして表示
- オブジェクト情報: エフェクト名、レイヤー番号、フレーム範囲を表示
- パラメータ表示: メインエフェクトおよびフィルタ効果のパラメータ値を表示

## 設定

設定メニュー → TimeLinePreview から開きます。

- サムネイル幅: ポップアップのサムネイル幅 (px)
- タイマー間隔 (ms): ホバー検出のポーリング間隔
- サムネイルを表示: サムネイルの表示/非表示
- ヘッダーを表示: レイヤー番号・エフェクト名・フレーム範囲の表示/非表示
- メインエフェクトのパラメータを表示: 数値パラメータの表示/非表示
- フィルタ効果を表示: フィルタ効果一覧の表示/非表示
- フィルタ効果のパラメータを表示: フィルタパラメータの表示/非表示
